# 📖 Overview

UniQuest is an intelligent learning platform designed to make education more engaging and personalized.

Instead of providing the same learning experience to every student, UniQuest uses AI to:

- 🧠 Analyze learning behaviour
- 📚 Recommend personalized courses
- 🎯 Generate study plans
- 📈 Track learning progress
- 🎮 Increase engagement using gamification
- 🏆 Reward consistent learners

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/UniQuest.git
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```
